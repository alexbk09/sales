# AmaxTech commercial landing

Next.js landing page for AmaxTech.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Commercial configuration

Plan names, prices, descriptions and feature lists are centralized in `lib/pricing.ts`.

The demonstration request form is frontend-only and opens the visitor's email application addressed to `ventas@amaxtech.com`. No lead is stored by the website.
